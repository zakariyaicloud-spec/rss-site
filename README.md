# r-s-s.com website

Static copy of the R-S-S (Regulatory Scientific & Health Solutions) website, hosted on GitHub Pages.

- Every page lives in its own folder as `index.html` (e.g. `about-us/index.html`).
- Images and files are in `wp-content/uploads/`.
- Site fonts are in `fonts/rss-fonts.css`.

To make a change, ask Claude (connected to this repo) to edit the page and push. The live site updates automatically a minute or two after each push to `main`.
